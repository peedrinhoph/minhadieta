Sobre o armazenamento

Esta versão não usa servidor nem conta: os dados ficam no armazenamento local do navegador. O backup JSON é a forma de levar a dieta para outro aparelho. Para instalação e funcionamento offline, publique os arquivos por HTTPS no GitHub Pages.
